01

Pickup desk

A shared spreadsheet became a daily pickup desk. Operators paste the day’s carrier lists, the server matches nicknames to official stops, fills a board, and confirms priced rows into the database.

  • Paste four lists and keep them by date
  • Correct official names, then fill and confirm
  • Edit locations, prices, and schedules in a catalog
  • Sign-in replaces “anyone with the link”
  • Next.js
  • React
  • TypeScript
  • Supabase Auth
  • Postgres

02

Auto inbound

There is no inbound API, so a PC watcher drives the dispatch site the way a person would. A spreadsheet menu only queues orders. Python and Playwright click through to storage and mark each one done.

  • Start a batch from the selected row
  • Walk each order until it reaches storage
  • Stop the batch on an unknown status
  • Trigger the next run from the sheet or a browser script
  • Python
  • Playwright
  • Apps Script
  • Sheets API

03

Sorting night

A local scraper keeps the night’s sort volumes in Postgres, and a city map says which chutes belong to which destination. A signed-in dashboard is the view on top of that database.

  • Timed scrapes across the operating night
  • City, chute, and route catalog
  • Opening volume captured when the batch changes
  • Dashboard gated by login, including a read-only guest
  • Python
  • Playwright
  • Supabase
  • Postgres

04

Nightly report

After 10pm the desk pulls delivery totals, ranks each DSP, and splits inactivity into driver, warehouse, and transit. The summary then goes out to the group chats.

  • Delivery, return, and inactive rates for the night
  • Inactivity attributed only where it belongs
  • Three beats: fetch, report, message
  • UniUni API
  • Power BI
  • Microsoft Teams
